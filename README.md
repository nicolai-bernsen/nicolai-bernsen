#### 🛠 Currently building

- **Jarvis**: my personal assistant. An MCP server on Cloudflare Workers gives Claude my Obsidian vault as memory, Home Assistant for the house and a Linear backlog. Claude plans new features, Codex writes them, and they ship themselves. *(private)*
- **Skaf**: a DIY partner for Denmark. It diagnoses the problem, plans the job and finds local prices to rent, buy or borrow the tools. *(private, testing with friends)*
- **[backlogd](https://github.com/nicolai-bernsen/backlogd)**: a Claude Code plugin that turns Claude into a problem-driven scrum team. You file a problem; it scopes it, solves it, reviews its own work and ships the result.

Want to build your own Jarvis? Start with open-source pieces like [whisper.cpp](https://github.com/ggml-org/whisper.cpp), [Ollama](https://github.com/ollama/ollama), [Home Assistant](https://github.com/home-assistant/core) and [MCP servers](https://github.com/modelcontextprotocol/servers).
